# 角色与视觉连续性

在角色跨镜头、跨集、换装、多人同框或使用多个生成工具时读取。目标是可验证的一致性，不承诺百分比。

> 相关：整体画风与色板见[视觉风格锚](craft-visual-style.md)；相邻镜头的接续见[镜头语言与分镜](craft-shot-language.md)；权利边界见[权利、安全与平台规则](rights-safety-and-platforms.md)。

## 身份锚点

使用[角色 Bible](../templates/character-bible.md)把信息分成三层：

1. **不变身份**：脸型、五官比例、发型核心轮廓、体型、标志物和基础色板。
2. **状态变化**：服装、发型变化、伤势、污渍、道具和年龄阶段，使用 `LOOK-01` 等编号。
3. **镜头变量**：表情、姿态、构图、光线和动作，不得改写前两层。

先批准一组参考包：正面、左右侧面、背面、全身比例、关键表情、服装细节和色板。参考图本身不一致时，不进入批量生产。

## 参考库工作流（最稳的默认路径）

当前主流模型都支持**多图参考**，因此一致性问题的正解不是"把描述写得更详细"，而是**建立一个参考库并反复引用它**：

1. **建一个标准图**：正面、均匀光、中性表情、干净背景、短边 ≥1024 像素。这一张是身份的唯一真源。
2. **扩成参考表**：以标准图为参考，分别生成正面、左右四分之三、侧面、微笑特写、全身比例——共 5–8 张，逐张人工批准。
3. **换装用编辑而不是重生成**：换衣服、换道具这类改动，用**区域编辑**（只改目标区域，脸与发型保持不变）而不是重新抽卡。
4. **每镜引用 2–4 张**：按这一镜需要的角度与表情从参考库里挑，并在提示里**显式说明哪张图管什么**（例如"图 1 提供脸与发型，图 4 提供全身比例与服装"）。
5. **永远回指参考库**：不要用"上一张满意的成品"去生成下一张。

**最容易被忽略的一条**：逐代传递会让偏差累积。第一镜 95% 像、第二镜像第一镜 95%、第三镜再打折……很快就不像了。**每次都回指原始参考库**，偏差才不会滚雪球。

## 策略选择

| 策略 | 适用 | 关键检查 |
|------|------|----------|
| 固定描述 + 参考图 | 所有路线的基础方案 | 每镜使用同一身份块和已批准参考 |
| 多参考/角色功能 | 支持多图参考的云端工具 | 核对当前支持的参考图数量、权重与商用条款 |
| 区域编辑（只改局部） | 换装、修补五官、替换道具 | 编辑区域是否精确；改完是否复核脸部未变 |
| 固定种子 | 同模型内重现与诊断 | 种子不保证跨模型或复杂姿态一致 |
| 图像适配器/姿态控制 | ComfyUI 等本地流程 | 身份、姿态、深度分别控制并做消融测试 |
| 角色 LoRA/微调 | 长期连载、超大量产出 | 训练集权利、质量、多样性和底模许可必须清楚 |
| 参考图生视频 | 从静帧进入动态 | 把静帧用的同批参考也挂进视频节点 |

不要把工具营销名称当稳定接口。使用前读取[工具目录](tools-catalog.md)和当前官方文档。

## 生成顺序

1. 锁定单人身份和基础造型。
2. 验证不同角度、表情和景别。
3. 验证场景光线与服装状态。
4. 再测试双人同框、遮挡和复杂动作。
5. 静态关键帧通过后再做视频。

每一步记录失败类型和有效参数，避免一次同时改变模型、提示词、参考图和种子。

## 漂移的四类成因（按发生频率排序）

| 成因 | 表现 | 处理 |
|------|------|------|
| **描述词在镜头之间悄悄变了说法** | 前几镜像，后面越来越不像 | 把身份与风格抽成固定文本块，逐镜原样粘贴 |
| **参考图选错或不干净** | 某一镜明显偏；五官年龄变了 | 用参考库里对应该角度的那张；剔除低质/带噪参考 |
| **逐代传递（用成品当参考）** | 越往后越糊、越像一个"平均脸" | 改回原始参考库 |
| **模型/工具/参数被中途更换** | 整集像两部片子 | 一集内尽量不换模型；必须换时重跑受影响镜头并做色彩统一 |

诊断顺序：**先查描述词 → 再查参考图 → 再查传递链 → 最后才怀疑模型**。

## 连续性检查

- **人物**：脸、发型、体型、年龄、服装编号、伤势和标志物。
- **空间**：人物站位、屏幕方向、视线、门窗和关键物体布局。
- **动作**：上一镜头的手、脚、道具和运动方向能否接到下一镜头。
- **摄影**：光源方向、色温、焦段感、景深和画幅。
- **声音**：音色、口音、发音、情绪强度和声场位置。

## 验收方法

一致性不能靠"看着差不多"验收。建议：

1. **同角度比对**：把每集里出现的同一角色正脸截出 3–5 帧并排看，重点看脸型轮廓、眼距、发际线与标志物。
2. **跨集比对**：上一集与这一集各取一帧同角度画面并排。
3. **关键道具单列**：标志物（耳环、伤疤、戒指、发饰）单独做一列检查，它们最容易在换装时丢失。
4. **记录证据**：不通过的镜头在[素材台账](../templates/asset-ledger.md)里标 `rejected` 并写明原因（脸漂/服装错/道具丢），方便统计哪一类错误最多。
5. **不要用平均分掩盖**：角色崩坏属于硬门禁，不因为其他项得分高就通过，见[质量评测与测试](quality-evaluation-and-tests.md)。

## 故障诊断

| 症状 | 先检查 | 最小修复 |
|------|--------|----------|
| 脸部漂移 | 参考图是否批准、身份块是否变化、是否逐代传递 | 降低镜头变量，补侧面/表情参考，回指原始库 |
| 衣服变色 | 是否绑定造型编号和色板 | 在任务卡写明 `LOOK-ID` 和颜色值/名称 |
| 双人融合 | 两人描述和位置是否可区分 | 分别锁定角色，明确左右与空间关系，必要时拆镜 |
| 动作变形 | 一镜动作过多或遮挡复杂 | 拆镜、增加中间关键帧或改用可控姿态 |
| 跨工具风格断裂 | 色彩、尺寸、锐度和去噪链不同 | 统一母版和后期规范，减少无必要换工具 |
| 侧脸/背影崩坏 | 参考库缺少该角度 | 补该角度的批准参考后再生成 |
| 换装后标志物丢失 | 换装用了整帧重生成 | 改用区域编辑，只改服装区域 |

真人肖像、声音或受保护角色还必须读取[权利、安全与平台规则](rights-safety-and-platforms.md)。
