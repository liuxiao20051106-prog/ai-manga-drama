# 镜头语言与分镜

在把剧本转成分镜、诊断「画面平」「跳轴」「镜头之间接不上」或确定竖屏构图策略时读取。SKILL.md 已内置底线（相邻镜头检查轴线、视线、动作接点、空间方向、服装、道具、光线），此处是完整展开。

> 相关：每镜该动什么见[动态化技法](craft-motion-design.md)；画风与色板统一见[视觉风格锚](craft-visual-style.md)；分镜表字段可用 `scripts/shotlist_lint.py` 机器校验。

## 一、景别五档与用途

| 景别 | 装什么 | 常见用途 | 竖屏调整 |
|------|--------|----------|----------|
| 大远景 | 环境、规模、孤立感 | 开场、结尾、时间推进 | 竖屏里易空洞，慎用；改成高角度俯拍 |
| 全景 | 人物全身 + 空间关系 | 建立角色位置、动作戏 | 人物占比要更大 |
| 中景 | 腰部以上 | 对话主战场 | 竖屏的"标准镜" |
| 近景 | 胸部以上 | 情绪、台词重点 | 使用频率最高 |
| 特写 | 脸/手/道具 | 情绪爆点、信息点 | 竖屏优势区，多用 |

**原则**：情绪越强，景别越近。一集里至少有一次"比常规更近"的镜头用来交付情绪高点。

## 二、机位与角度

- **平视**：中性、客观，对话常用。
- **俯视**：压小人物，表现弱势、被注视、孤独。
- **仰视**：放大压迫感，表现强势、威胁。
- **过肩**：把观众放进对话，制造"在场感"。
- **主观镜头**：让观众直接进入角色视角，代价是看不到角色自己的表情——用于关键信息揭露最有效。

**机位变化要服务情绪，不要为了热闹而换**。同一个对话场景连续切换三个机位，观众感受到的是不安——如果你要的是平静，那就别切。

## 三、轴线与空间方向（最容易致命的一条）

- **180° 轴线**：两人对话时，所有机位保持在同一侧。越轴会让观众觉得两人位置互换。
- **视线匹配**：A 看画面的右，B 就应该看画面的左。反了会让观众觉得两人没在互看。
- **运动方向**：向左行进的人，下一个镜头要继续向左；突然反向会被读成"回头了"。
- **需要越轴时**：用一个中性镜头（骑轴）或明确的移动镜头过渡，让观众看到空间变化。
- **建立镜头**：新场景开头给一个能说明空间关系的镜头（全景/俯拍），之后的近景才不会让观众迷路。

## 四、动作接点（match on action）

上一镜的动作在下一镜继续，是让两个生成片段"缝"起来最便宜的手法：

- 开门的一半在 A 镜，跨进门在 B 镜；
- 抬手的一半在 A 镜，放到对方肩上在 B 镜。

**配合生成工具的用法**：把 A 镜的**结束帧**作为 B 镜的**起始帧**（首尾帧衔接），或在分镜表里同时写清"入镜状态/出镜状态"，这样两个片段接起来观众看不出是分段生成的。

## 五、一镜一动作

生成式视频在"一个镜头里塞两个动作"时最容易崩（变脸、多手、物体穿透）。因此分镜阶段就要拆：

- 一镜只表达一个**可冻结的动作节点**（"转头"是动作，"转头并站起来拿包"是两个）。
- 复杂动作拆成 2–3 镜，或补一张中间关键帧。
- 数字、文字、复杂手势尽量不要写进生成提示词——放到后期排版。

## 六、场景的三段式构建

同一个场景内，用景别的推进来引导观众：

```
建立镜头（谁在哪）→ 中景（发生什么）→ 近景/特写（感受什么）
                        ↘ 反向镜头（对方反应）→ 再回到近景
```

一段对话至少要有 **说话人 → 听话人反应** 的切换。只拍说话人，观众会觉得像会议录像。

## 七、省略与转场

- **跳切**：同一机位切掉中间过程，表达时间流逝或重复；节奏快、适合搞笑与焦虑。
- **动作接点转场**：最顺滑，见第四节。
- **遮挡转场**：人物/物体挡满画面时切换，天然掩盖不连续。**生成片段时最实用的转场**。
- **声音先行**：下一场的声音提前进入，画面后到，衔接感更强。
- **叠化/淡入淡出**：表达时间跨越或情绪收束，短视频里用得越少越好。
- **图形匹配**：圆形的月亮 → 圆形的灯；形状相同的东西接在一起。

原则：能用一个动作接起来，就不要用特效。转场越少，作品越"稳"。

## 八、竖屏 vs 横屏的分镜差异

| 维度 | 竖屏 9:16 | 横屏 16:9 |
|------|-----------|-----------|
| 主要景别 | 中景/近景/特写为主 | 全景/中景为主 |
| 并排人物 | 最多 2 人，且要前后错位 | 可容 3 人并排 |
| 空间交代 | 靠纵向层次（前景/中景/远景） | 靠横向铺陈 |
| 运镜偏好 | 纵向推拉、跟随、轻微 handheld | 横移、摇镜、升降 |
| 字幕占位 | 下方约 20% 需要预留 | 下方约 10% |

做多平台时**不要用裁切**：竖屏改横屏要重新安排构图（加留白、重做字卡、补环境），否则人物会被切掉半张脸。

## 九、分镜表怎么写才"可拍摄"

每镜必须能回答：

1. **谁在画面哪里**（左右、前后、朝向、视线）
2. **这一镜的一个动作是什么**（可冻结的一瞬间）
3. **景别与机位**（近景 / 平视 / 过肩）
4. **入镜状态**（承接上一镜的什么）
5. **出镜状态**（下一镜需要接上什么）
6. **时长**与**声音接点**（台词、音效、音乐进入点）

字段写不全的分镜，到了生成环节一定会返工。用[分镜表](../templates/shot-list.md)填，再用脚本检查：

```bash
python scripts/shotlist_lint.py 分镜表.md --target-seconds 60
```

## 十、分镜自检清单

- [ ] 轴线与视线方向在相邻镜头间保持一致？
- [ ] 有人物出画/入画时，运动方向连续？
- [ ] 每个新场景都有建立镜头？
- [ ] 每镜只表达一个主要动作？
- [ ] 相邻镜头的入镜/出镜状态能对接（可优先用首尾帧）？
- [ ] 一集里有至少一次更近的景别用于情绪高点？
- [ ] 对话有"听话人反应"的镜头？
- [ ] 转场是否尽量少而自然？
- [ ] 竖屏构图下人物是否足够近、信息是否在纵向分布？
