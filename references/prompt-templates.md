# 漫剧提示结构库

在需要把任务卡转为剧本、图像、视频、声音或音乐提示时读取。先使用模型无关结构，再按当前工具文档添加参数；不要把旧版本号或营销词长期写死。

## 剧本提示

```text
任务：为 [项目/集号] 生成 [时长] 的可拍摄漫剧剧本。
事实源：[已确认人物、世界、上一集状态]
本集目标：[角色目标、阻力、变化、情绪起止]
必须保留：[内容]
禁止新增/修改：[内容]
交付：[分场、动作、对白/旁白、声音、视觉重点、预计时长]
检查：总时长、因果、可视化程度、连续性和待确认新事实。
```

不要机械要求“每句不超过固定字数”或“固定三秒钩子”。用实际语速、表演停顿、字幕可读性和平台体验决定。

## 角色设定图

```text
[CHAR-ID / LOOK-ID]
身份锁：[脸型、五官、发型核心、体型、标志物]
造型锁：[服装、颜色、材质、鞋、道具]
本次变量：[表情、姿态、视角]
交付视图：[正面、侧面、背面、全身比例、表情]
画面语言：[线条、色板、材质、光线、细节密度]
背景：[中性、便于审查轮廓]
负面约束：[禁止漂移、文字、水印、额外肢体等]
```

不要直接写“某位在世艺术家/导演风格”。把需求拆为高层视觉特征。

## 场景锚点

```text
[LOC-ID]
空间结构：[入口、窗、家具、道路、地标及相对位置]
时间/天气：[内容]
主光源与色温：[内容]
关键道具及位置：[内容]
构图用途：[建立镜头/对话/动作区域]
画面语言：[内容]
空镜，无角色；保持后续镜头可复用。
```

## 分镜关键帧

```text
[E01-S001]
引用资产：[CHAR-ID/LOOK-ID、LOC-ID、PROP-ID]
空间与位置：[谁在画面哪一侧，朝向和视线]
动作瞬间：[单一、可冻结的动作节点]
构图：[景别、机位、镜头感、主体层次]
光线/氛围：[沿用场景锚点，仅写必要变化]
连续性入口：[上一镜头出口]
连续性出口：[下一镜头需要的状态]
负面约束：[身份、服装、道具、文字和肢体]
```

## 图生视频

```text
基于 [E01-S001 已批准关键帧]。
主体动作：[谁、从什么状态到什么状态]
环境动作：[只写必要动态]
镜头运动：[方向、速度、起止]
时间演进：[节奏、停顿、光线变化]
保持不变：[身份、服装、道具、背景结构、画风]
结束帧：[下一镜头需要衔接的状态]
```

一个镜头优先一个主动作。源图已确定的外貌不要重复堆叠，以免模型重新解释。

## 配音

```text
[AUD-ID / CHAR-ID]
台词：[内容]
语言与发音：[专名、重音、数字读法]
情绪目标：[主情绪 + 克制/强度]
语速与停顿：[按表演需要]
声音边界：[年龄感、音域、禁止模仿对象]
对应镜头/时间码：[内容]
```

只有本人或有书面授权的声音才能进入克隆流程。普通合成音也要核对商业条款。

## BGM 与音效

```text
用途：[集号、时间段、情绪功能]
音乐特征：[速度范围、节奏密度、乐器、和声、起伏]
需要避让：[对白频段、关键音效、停顿]
结构：[进入、发展、高潮、退出、是否循环]
禁止：[可识别歌曲/旋律、未授权声音或采样]
```

生成后仍需试听、编辑和权利记录。提示词相似不代表输出天然可商用。
