# 角色一致性技术详解

角色一致性（Character Consistency）是 AI 漫剧制作中最大的技术挑战。同一角色在不同分镜、不同场景、不同动作中保持"同一张脸"，是专业漫剧和业余作品的分水岭。

---

## 方案一览

| 方案 | 难度 | 效果 | 路线适用 | 原理 |
|------|------|------|---------|------|
| 1. 参考图法 | ⭐ | ★★★ | A/B/C | 生成满意角色 → 后续生图以此为图生图参考 |
| 2. 统一关键词法 | ⭐ | ★★★ | A/B/C | 固定角色描述+画风关键词，复制粘贴不变 |
| 3. 即梦智能画布 | ⭐ | ★★★★ | A专属 | 即梦内置功能，可锁定角色形象 |
| 4. 角色ID/种子固定 | ⭐⭐ | ★★★★ | A（可灵/Vidu） | 固定随机种子+角色参考图 |
| 5. LoRA 微调 | ⭐⭐⭐ | ★★★★★ | C专属 | 训练角色专属LoRA权重 |
| 6. IP-Adapter | ⭐⭐⭐ | ★★★★★ | C专属 (ComfyUI) | 注入身份嵌入向量 |
| 7. Character Cameo | ⭐⭐ | ★★★★★ | B（Sora2） | API 内置角色一致性功能 |

---

## 方案 1：参考图法（新手首选）

### 原理
生成一张满意的角色设定图后，后续所有分镜都以这张图为"参考图"，使用工具的图生图或参考图功能来保持一致性。

### 操作步骤

1. **生成人设卡**：用高质量的提示词生成角色三视图/设定图
2. **挑选最佳图**：从多张生成结果中选最满意的一张
3. **后续出图**：每次生图时将人设卡设为参考图
   - **即梦**：使用"智能画布"或"参考图"功能
   - **可灵**：使用"参考图生成"
   - **Midjourney**：使用图片URL作为参考（`--iw` 参数控制参考权重）
   - **SD/ComfyUI**：使用 img2img 或 ControlNet Reference

### 优缺点

| 优点 | 缺点 |
|------|------|
| 操作极其简单 | 角色在不同角度/动作下仍可能变形 |
| 不需要任何技术基础 | 无法做到 100% 一致 |
| 所有路线都支持 | 光线/场景变化大的情况下效果下降 |

### 提示词配合技巧

在后续分镜提示词的开头加上：
```
（参考角色X的人设卡图）
```
这样提醒自己标记使用了哪张参考图，也方便工具理解。

## 方案 2：统一关键词法

### 原理
在所有人设卡和分镜提示词中使用一模一样的角色描述和画风关键词，确保 AI 拿到的是完全一致的文本输入。

### 操作步骤

1. **写一份角色描述模板**并锁死
2. **写一份画风关键词模板**并锁死
3. **每个分镜提示词都复制粘贴**这些固定内容

### 模板示例

```
# === 固定角色描述（每个分镜都要复制这一段）===
角色描述：18岁少年，黑色刺猬头，剑眉星目，黑色瞳孔，小麦色皮肤，红色连帽卫衣，深蓝校服外套，黑色长裤，白色运动鞋，左手腕电子表

# === 固定画风关键词（每个分镜都要复制这一段）===
画风：日系少年漫画风格，轮廓线条利落有力，高明暗对比

# === 分镜专用描述（每个分镜不同）===
[S01] 站在教室窗前，逆光剪影，全景
[S02] 侧脸特写，嘴角上扬微笑，近景
[S03] 走在街道上回头一瞥，中景
```

### 优缺点

| 优点 | 缺点 |
|------|------|
| 零成本，纯文本操作 | 仅靠文本控制，精度有限 |
| 可作为其他方案的补充 | 不同模型对相同文本的理解有差异 |
| 适合所有路线 | 无法解决模型自身的随机性 |

## 方案 3：即梦智能画布（A路线专属）

### 原理
即梦的"智能画布"功能可以在画布上固定角色形象，后续在画布上生成新内容时自动保持角色一致。

### 操作步骤（概要）
1. 在即梦中生成并确认角色形象
2. 使用智能画布功能锁定角色
3. 在画布上切换场景继续生成

> **提示**：这是目前国产工具中对新手最友好的角色一致性方案。如果用户选择 A 路线，优先推荐此方案。

---

## 方案 4：角色 ID / 种子固定

### 原理
部分工具（可灵、Vidu 等）支持固定随机种子（seed），配合相同的提示词和参考图，可以大量减少随机变化。

### 操作步骤
1. 生成满意的第一张角色图，记录其 seed 值
2. 后续生成相同角色时使用相同的 seed
3. 配合参考图法使用效果更佳

### 适用工具
- 可灵（参考图 + seed 固定）
- Vidu（角色 ID 功能）
- Midjourney（`--seed` 参数）
- Stable Diffusion（固定 seed）

## 方案 5：LoRA 微调（C路线，效果最佳）

### 原理
收集同一角色的 20-50 张高质量图片，用 Kohya_ss 训练一个 LoRA 模型。之后在 Stable Diffusion 中调用该 LoRA，所有生成结果天然保持角色一致。

### 前置条件
- NVIDIA GPU（12GB+ VRAM）
- 已部署 Stable Diffusion WebUI 或 ComfyUI
- 安装了 Kohya_ss

### 操作步骤概要

**1. 准备训练集（最关键的步骤）**
- 数量：20-50 张
- 内容：同一角色的不同角度（正面/侧面/半侧面）、不同表情、不同光线
- 质量：高分辨率、清晰、画风统一
- 来源：先用 MJ/即梦 生成多张候选、手动筛选最好的

**2. 打标（Caption）**
- 用 WD14 Tagger 自动打标
- 手动修正标签，添加角色专属触发词（如 `sakuragirl`）

**3. 训练参数（入门推荐）**
```
- 底模：SDXL 或 Illustrious
- LoRA rank：16-32
- 训练步数：1500-3000
- 学习率：0.0001
- 优化器：AdamW8Bit
```

**4. 使用**
- 在提示词中加入触发词 `sakuragirl`
- LoRA 权重：0.7-1.0（根据效果调整）
- 配合 ControlNet 控制构图和姿态

### 优缺点

| 优点 | 缺点 |
|------|------|
| 一致性最高（90%+） | 需要技术基础 |
| 训练一次，所有图都一致 | 训练时间 30-60 分钟 |
| 可控性极强 | 需要较好的 GPU |
| 可无限使用 | 训练集质量决定 LoRA 质量 |

### 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| LoRA 效果不明显 | 权重太低 | 提高到 0.8-1.0 |
| 角色"过拟合" | 训练集太小/太单一 | 增加训练集多样性，降低训练步数 |
| 画风被 LoRA 扭曲 | LoRA 权重太高 | 降到 0.5-0.7 |
| 训练出"鬼影" | 训练集画风不统一 | 统一画风后重新收集训练集 |

## 方案 6：IP-Adapter（C路线 ComfyUI）

### 原理
IP-Adapter（Image Prompt Adapter）直接将参考图像的"身份"信息注入到 Stable Diffusion 的去噪过程中，不需要训练。

### 前置条件
- ComfyUI 已安装
- 安装了 IP-Adapter 节点包

### ComfyUI 工作流核心节点
```
Load Image (人设卡参考图)
    ↓
IP-Adapter Model Loader
    ↓
IP-Adapter Apply (连接到 KSampler)
    ↓
同时输入：文本提示词 + ControlNet（控制构图）
```

### 参数建议
- IP-Adapter 权重：0.5-0.8（太高会压过文本提示词）
- 配合 ControlNet OpenPose（控制姿态）+ Depth（控制景深）
- 底模推荐：SDXL 或 Illustrious

### 优缺点

| 优点 | 缺点 |
|------|------|
| 不需要训练 | 需要 ComfyUI 技术基础 |
| 即时生效 | 一致性不如 LoRA（80-85%） |
| 一张图即可 | 复杂动作/角度可能漂移 |
| 与 LoRA 可叠加使用 | 调参需要经验 |

## 方案 7：Character Cameo（B路线，Sora2 专属）

### 原理
Sora 2 内置的 Character Cameo 功能，只需提供一张角色参考图，模型自动在所有生成视频中维持该角色的外貌一致。

### 使用方式
1. 在 Sora 中上传角色参考图（高质量正面照最佳）
2. 在提示词中引用该角色
3. 模型内部处理一致性

### 优缺点

| 优点 | 缺点 |
|------|------|
| 全自动，无需任何额外操作 | 仅 Sora 2 支持 |
| 一致性效果优秀 | 需要付费订阅 |
| 视频和角色一致性一体化 | 不支持自定义训练 |

## 进阶：多方案组合策略

最佳实践往往是组合使用多个方案：

### 新手推荐组合
```
参考图法 + 统一关键词法 + 即梦智能画布
可靠性：70-80% | 成本：0 | 难度：极低
```

### 进阶推荐组合
```
LoRA（角色身份） + ControlNet（姿态控制） + IP-Adapter（参考加固）
可靠性：90-95% | 成本：GPU 电费 | 难度：中高
```

### 专业推荐组合
```
LoRA + IP-Adapter + ControlNet(OpenPose+Depth) + FaceDetailer(面部增强)
可靠性：95%+ | 成本：GPU 电费 | 难度：高
```

## 一致性诊断流程图

```
角色变脸了？
    │
    ├─ 轻微差异（还能认出是同一个角色）
    │   └─ 加强统一关键词法 + 检查画风关键词是否一致
    │
    ├─ 明显差异（有时像有时不像）
    │   └─ 换用参考图法 + 降低 prompt 的 creativity/CFG 参数
    │
    └─ 完全不像（每张图都是不同的人）
        ├─ A路线 → 改用即梦智能画布
        ├─ B路线 → 换 Sora2 用 Character Cameo
        └─ C路线 → 考虑训练 LoRA
```
