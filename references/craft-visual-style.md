# 视觉风格锚

在确定画风、跨镜头/跨工具保持风格统一，或诊断「画风割裂」「同一集里像两部片子」时读取。SKILL.md 已内置底线（不要求模仿在世创作者或具体作品，改写为高层视觉特征），此处给出可操作的做法。

> 相关：角色与造型的连续性见[角色一致性](character-consistency.md)；场景锚点提示结构见[提示词模板](prompt-templates.md)；风格锚的填写模板见[风格指南](../templates/style-guide.md)。

## 一、风格必须被"定义"才能被复现

"日系动漫风""国风"这类词对模型来说等于没写。把风格拆成下面六个可观察维度，每个维度给一个明确取值：

| 维度 | 取值示例 |
|------|----------|
| **线条** | 粗细（细勾线／粗描边）／颜色（黑线／深棕线／彩色线）／是否有断笔 |
| **上色** | 平涂／赛璐璐／厚涂／水彩晕染／网点；阴影是硬边还是软边 |
| **色彩** | 饱和度（低饱和灰调／高饱和明快）／主色倾向（暖橙／冷蓝／墨绿） |
| **光影** | 光源数量与方向（单侧逆光）／光斑、体积光、边缘光的有无 |
| **细节密度** | 背景信息量（极简留白／繁复堆砌）／材质表现（布料褶皱、金属反光） |
| **比例与镜头感** | 头身比（3 头身／7 头身）／透视强弱／画幅留白习惯 |

把这张表写进[风格指南](../templates/style-guide.md)，之后每一条提示词都引用同一份取值——**风格漂移的根源通常是描述词在镜头之间悄悄换了说法**。

## 二、风格锚三件套

跨镜头、跨工具、跨会话保持一致，只需要三样东西随身带：

1. **风格块文本**（60–120 字）：把上一节的六个维度压成一段固定文字，每次生成原样粘贴。
2. **色板**：主色 1–2 个、辅色 2–3 个、强调色 1 个，写成十六进制或准确色名；再附一份"时段色温表"（清晨/正午/黄昏/夜/雨），保证同一场景在不同镜头里色温一致。
3. **参考图库**：2–4 张已批准的画面（不是角色定妆照，而是**最能代表整体观感的场景图**）。

**规则**：风格块像身份块一样固定，只有"镜头变量"部分允许改。想调风格，就升版本（`STYLE-v01 → v02`），并同步更新所有未制作的镜头，不要在单镜上临时改。

## 三、参考图怎么挑

参考图的质量决定输出质量，挑图标准：

- **干净**：背景简单、无强阴影、无杂物、无文字水印。
- **均匀光**：正面或柔和侧光，避免大面积死黑与过曝。
- **清晰**：短边 ≥1024 像素（越高越稳），不要从压缩过的成品视频里截帧。
- **中性姿态**：正面、自然表情、不要极端角度。
- **一致**：参考图之间本身不能互相矛盾（三张图三种发型＝制造漂移）。

**不要用"上一张满意的成品"作为下一镜的参考**——逐代传递会让偏差累积。始终回指**原始参考库**。

## 四、跨工具与跨环节的统一

工具越多，越要在中间环节做统一。按环节分工：

| 环节 | 统一措施 |
|------|----------|
| 图像生成 | 同一风格块 + 同一参考库；尽量在同一模型内完成同一集的画面 |
| 混合模型 | 统一先转成同一色彩空间与分辨率，再做后期；记录每个镜头的来源模型 |
| 后期调色 | 母版加统一的 LUT/滤镜；同一场景的色温、对比、锐度参数写进规范 |
| 分辨率与锐度 | 定一个交付母版分辨率，其余镜头统一缩放/锐化，避免"有的糊有的利" |
| 去噪与压缩 | 统一编码参数；不要混用不同工具的多次压缩产物 |

**一次只换一个变量**：换模型、换提示词、换参考图、换种子如果同时发生，出了问题无法归因。

## 五、风格漂移诊断

| 症状 | 先查 | 最小修复 |
|------|------|----------|
| 单镜画风不同 | 风格块文本是否被改写 | 恢复为固定风格块原文 |
| 整体越来越"糊" | 是否在用成品做参考（逐代递传） | 改回原始参考库 |
| 前后两集像两部片子 | 是否换了模型/工具 | 用同一风格锚重跑受影响镜头，或统一后期 LUT |
| 色彩忽然变冷/变暖 | 参考图或场景时段色温不一致 | 按色温表逐镜校对 |
| 线条粗细不一 | 风格描述里线条维度缺失 | 在风格块中明确线条取值 |
| 细节密度忽高忽低 | 镜头变量写得过满 | 把细节描述移入风格块，变量只留动作与构图 |

## 六、边界：可以做的高层特征，不可以做的复刻

**可以**：描述媒介（赛璐璐动画、水彩、木刻版画、水墨）、构图规律、色彩关系、光影逻辑、材质表现、比例风格、叙事距离。

**不可以**：指名要求模仿某位在世创作者的签名风格、某个具体作品的可识别角色设计或画面；这既是权利风险，也让作品失去自己的辨识度。

需要向某个方向靠拢时，把参考"翻译"成上一节的六个维度——**翻译的过程本身就是创作**。

## 七、自检清单

- [ ] 六个维度都有明确取值，并写进风格指南？
- [ ] 每次生成都用了同一段风格块文本？
- [ ] 色板与时段色温表已定，并在各镜头间核对过？
- [ ] 参考库是干净、清晰、互相一致的，且没有被成品逐代替换？
- [ ] 混用工具时，是否做过色彩/分辨率/锐度统一？
- [ ] 风格调整是否走了版本升级，而不是在单镜上临时改？
