# 动态化技法

在决定"这张静态图怎么动"、诊断「画面像 PPT」「一生成就崩」或规划图生视频策略时读取。SKILL.md 已内置底线（一镜一主要动作、检查闪烁/变脸/肢体/穿透/方向、不无限重试），此处是完整展开。

> 相关：分镜怎么拆见[镜头语言与分镜](craft-shot-language.md)；图生视频提示结构见[提示词模板](prompt-templates.md)；画风连续性见[视觉风格锚](craft-visual-style.md)。

## 一、动态强度四档：先选档，再选工具

不是每一镜都需要"生成式动画"。先按这一镜的任务定档，能省掉大量失败与成本：

| 档位 | 做法 | 适用 | 成本/风险 |
|------|------|------|-----------|
| **1 静态微动** | 原图 + 轻微缩放/位移/视差 + 光效/粒子 | 情绪停留、旁白、氛围镜 | 最低；几乎不会崩 |
| **2 2.5D 分层** | 前景/中景/背景分层，各自以不同速度位移 | 空间感、镜头推移、漫画感 | 低；只需拆层 |
| **3 局部驱动** | 只让局部动（眨眼、嘴、发丝、衣摆），其余保持 | 对话镜、特写 | 中；需遮罩/驱动 |
| **4 全生成动画** | 图生视频模型整帧重绘 | 动作镜、转场镜、关键戏 | 最高；变脸与肢体风险集中在此 |

**经验配比**：一集里 1、2 档占一半以上，3 档用于有台词的镜头，4 档只留给真正需要动作的少数镜头。全程 4 档既贵又容易崩。

## 二、微动清单（把静态图救活的最小动作）

给画面加下面任意 2–3 项，观感就会从"图片"变成"镜头"：

- **呼吸**：人物胸腔/肩膀极小幅上下（1–2% 幅度）
- **眨眼**：每 2–4 秒一次，不要规律
- **发丝/衣摆**：随风小幅摆动，方向统一
- **光影流动**：云影掠过、窗帘透光变化、烛火晃动
- **空气感**：飘尘、雪花、雨丝、蒸汽、落叶
- **镜头呼吸**：极缓的推或拉（整镜幅度 3–8%）
- **水/反光**：水面波纹、玻璃反光偏移

这些都可以在剪辑软件里用关键帧 + 少量素材叠加完成，不必依赖生成模型。

## 三、2.5D 分层视差

把一张图拆成 3–5 层（背景 / 中景 / 人物 / 前景遮挡 / 光效），按层级给不同位移速度，就是最稳的"动起来"：

1. 拆层（图像编辑软件按选区抠出，或让图像模型分别生成"只有前景遮挡"的图层）。
2. 每层单独一张透明 PNG。
3. 在剪辑软件里：背景位移最小，前景位移最大，形成纵深。
4. 加一层缓动（先快后慢）避免机械感。

**典型用法**：镜头横移穿过场景、人物留在画面中心而背景流动、漫画风格的"推镜"。

## 四、运镜：怎么描述才生效

图生视频提示词里，运镜要写**方向 + 速度 + 起止**，而不是写"电影感镜头"：

| 运镜 | 描述要点 | 注意 |
|------|----------|------|
| 推 | 从全景到近景、缓慢、匀速 | 幅度别太大，否则人物会变形 |
| 拉 | 从近景退到全景、结尾减速 | 适合收尾与揭露 |
| 摇 | 从左到右、跟随视线 | 方向必须与轴线一致 |
| 移 | 平行移动、保持主体在画面同一位置 | 竖屏里位移要小 |
| 跟 | 跟随人物动作、轻微滞后 | 与人物运动方向一致 |
| 手持 | 轻微不规则晃动、幅度小 | 用多了会显得廉价 |

**原则**：一个镜头只写一种运镜。写好起止状态后，模型才知道往哪走。

## 五、与生成流程的配合

1. **先锁关键帧**：先把这一镜的入口帧与出口帧各自生成并批准，再生成中间动态。
2. **首尾帧衔接**：上一镜的结束帧直接作为下一镜的起始帧，跨镜衔接最稳。
3. **一镜一动作**：见[镜头语言与分镜](craft-shot-language.md)。
4. **复杂动作拆镜**：剧烈动作（打斗、奔跑、转身）拆成 2–3 个短镜，比一个长镜头成功率高得多。
5. **不重复描述外貌**：源图已经定了身份，视频提示再写一遍脸和衣服会让模型重新解释、导致漂移。只写动作、环境动态、镜头、时间演进。
6. **不无限重试**：设次数/成本上限，同类失败三次就停下来换思路（改分镜、改档位、换工具）。

## 六、失败模式与修复

| 症状 | 常见原因 | 最小修复 |
|------|----------|----------|
| 闪烁/帧间不稳 | 模型时序一致性差；画面细节过多 | 降低动态幅度、减少细节、换档位到 1/2 |
| 变脸 | 提示里重复描述了外貌；参考图未挂或过弱 | 只留动作描述，重新挂参考库 |
| 肢体畸变 | 一镜动作过多、遮挡复杂 | 拆镜、加中间关键帧、改用具象姿态参考 |
| 物体穿透 | 生成模型不理解空间关系 | 改成静态微动，或在后期用遮罩遮挡 |
| 运动方向错 | 提示未写方向，或与轴线冲突 | 明确写方向；检查与上一镜方向一致 |
| 画面整体"融化" | 动态幅度过大 | 把动作幅度缩到 30–50% 再试 |
| 时长不够 | 模型单次时长上限 | 用首尾帧接第二段，或用 1/2 档延长 |

## 七、音画同步的接点

动态化必须和声音一起规划，否则会出现"动作做完了台词还没说完"：

- 在分镜表里为每镜标注**声音接点**（台词起止、音效落点、BGM 进入/退出）。
- **音效落点**与画面动作对齐（关门声要落在门关上的那一帧）。
- 台词长度决定镜头时长：先量台词，再定镜头，而不是反过来。
- 需要口型的镜头见[台词、配音与声音](craft-dialogue-voice-and-sound.md)。

## 八、自检清单

- [ ] 这一镜的动态档位是有意选的，还是默认用了全生成？
- [ ] 静态微动/分层视差能省下的镜头，是否已经省掉？
- [ ] 提示词里只写了动作、环境动态、镜头、时间，没有重复描述外貌？
- [ ] 一镜只有一个主要动作？
- [ ] 与上一镜的首尾帧/运动方向衔接得上？
- [ ] 声音接点是否已标注，动作与音效是否对齐？
- [ ] 重试次数与预算是否设了上限？
