## 混合路线推荐

实践中最佳方案往往是混合路线：

| 混合方式 | 配置 | 适用场景 |
|---------|------|---------|
| **A+B混合** | 剧本(DeepSeek) + 图片(Midjourney) + 视频(可灵) + 配音(剪映) + 剪辑(剪映) | 画质升级但控制成本 |
| **A+C混合** | 剧本(DeepSeek) + 图片(ComfyUI+SD) + 视频(可灵) + 配音(剪映) | 图片完全可控，视频用云服务 |
| **B+C混合** | 剧本(Claude) + 图片(ComfyUI+LoRA) + 视频(Veo3/Sora2) + 配音(ElevenLabs) | 追求极致质量，角色一致性用LoRA |
| **全A起手 → 升级** | 第1-3集全A免费 → 第4集起逐步替换B/C工具 | 最低风险验证故事和流程 |
