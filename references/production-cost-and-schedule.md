# 成本、产能与排期

在估算预算、决定更新频率、诊断「一直在做但出不了片」或规划样片到量产的爬坡时读取。目标是**可核算、可复现**，不是预测收益。

> 相关：重试与幂等的工程约束见[自动化工作流](automation-workflow.md)；记录与回填见[项目与连续性](project-and-continuity.md)；平台收益结构见[商业化与分析](commercialization-and-analytics.md)。

## 一、唯一有意义的成本指标：每支可用成片的成本

单个镜头的价格是假指标。真正要算的是：

```
每支可用成片成本 =（生成额度 + 订阅 + 算力电费 + 人工工时折算 + 授权费）÷ 可用成片数
```

关键在**分母**：把失败与返工算进去。同一个镜头生成 4 次只留下 1 次，那么 4 次的花费都要摊到那 1 次上。

**别只比单价，比"命中率"**：单价低但命中率 25% 的工具，通常比单价高一倍但命中率 75% 的工具更贵。

用脚本先把量级算出来：

```bash
python scripts/budget_estimate.py --shots 42 --seconds 6 --attempts 2.5 --unit-cost 0.6 --target-seconds 180
```

（单价与额度按你实际使用的工具填写；具体数字随时会变，务必以当前官方页面为准。）

## 二、单集工时的乘算模型

```
单集工时 ≈ 镜头数 × 每镜尝试次数 × (生成等待 + 审查挑选 + 返工)
         + 剧本与分镜（一次性，随熟练度下降最快）
         + 配音/音乐/字幕
         + 合成与终检
```

**经验规律**：

- 前三集最贵——锚点（角色、场景、风格）建立完成后，后续每集的边际成本会明显下降。
- **锚点阶段不要省**：省一小时，后面每一集都要多花两小时修漂移。
- 把"等待"利用起来：生成排队时去写下一集剧本或做上一集后期，是产能提升最直接的手段。

## 三、失败率与重试预算

每个环节都要写死上限，否则预算会被吃光：

| 环节 | 建议上限（按项目规模调整） | 触发后动作 |
|------|---------------------------|-----------|
| 单镜生成尝试 | 3–5 次 | 停手：改分镜、改动态档位或换工具 |
| 同类失败 | 3 次 | 判定为"方法错"，不要继续抽卡 |
| 单集返工比例 | 20–30% | 超了就重审锚点与风格块 |
| 单集总花费 | 预算硬上限 | 超限先交付当前可用版本，再决定是否加投 |

**"再试一次就好"是产能最大的敌人**。设定上限是为了让失败早暴露，而不是让它在整季里累积。

## 四、样片 → 小批 → 量产的三道闸门

**不要一上来做整季。** 按阶段爬坡，每道闸门都要有明确的通过条件：

| 阶段 | 做什么 | 通过条件 |
|------|--------|----------|
| **① 样片** | 1 个 15–30 秒片段或 1 集最简闭环 | 角色不漂、风格统一、声音可用、作者认可方向 |
| **② 小批** | 3–5 集 | 每支可用成片成本稳定、失败率收敛、更新节奏能承受 |
| **③ 量产** | 整季/连载 | 前两阶段的参数固化成模板与清单，可交接给他人执行 |

每道闸门之前，把"要不要继续"当成一个明确的决策点，而不是默认继续。

## 五、排期

排期表至少包含四列：**集号 / 目标交付日 / 当前状态 / 阻塞点**。另外留出三类缓冲：

- **审核缓冲**：平台与作者审阅需要时间，且可能退回。
- **失败缓冲**：按上一阶段的真实失败率预留（通常 20–40%）。
- **休息缓冲**：日更时尤其重要——连续高强度会直接反映在质量与决策上。

**更新频率必须由真实产能倒推**，不要先定"日更"再硬扛。稳定更新 > 爆更后断更。

## 六、成本构成清单（别漏项）

- 生成额度 / 订阅（图像、视频、配音、音乐）
- 硬件与电费（本地路线：显卡折旧、电价、维护时间）
- 人工工时（编剧、分镜、挑选、后期、审校）
- **授权费**：音乐、音效、字体、参考素材、真人肖像/声音
- 存储与传输（多版本素材体积增长很快）
- 返工成本（按失败率折算）

本地路线看起来"免费"，但显卡折旧与电费要算进去；付费路线看起来贵，但省下的时间也是成本。两条路线都要按**每支可用成片成本**比较。

## 七、记录与复盘

- 每镜的尝试次数、命中情况、花费写入[生产运行日志](../templates/production-run-log.md)。
- 每集结束后记录：实际工时、实际花费、返工比例、失败最多的环节。
- **找瓶颈的方法**：按环节统计"吃掉的时间/预算占比"。如果 70% 花在同一件事上（通常是角色漂移或动作崩坏），就针对它改流程，而不是整体加班。

## 八、自检清单

- [ ] 每支可用成片成本算出来了吗（含失败与授权）？
- [ ] 每镜的尝试次数上限、同类失败上限、单集预算上限都定了吗？
- [ ] 是否先做样片、再小批、最后量产？
- [ ] 锚点阶段是否留够了时间？
- [ ] 更新频率是从真实产能倒推的，还是拍脑袋定的？
- [ ] 排期里有没有审核、失败、休息三类缓冲？
- [ ] 每集是否有实际花费与失败环节的记录？
