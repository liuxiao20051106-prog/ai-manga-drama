# 台词、配音与声音设计

在写台词、规划配音与口型、做混音与字幕，或诊断「听着别扭」「音画不同步」「台词塞不下」时读取。SKILL.md 已内置底线（克隆只使用本人或有书面授权的声音、字幕按实际音频校对、混音以对白可懂度为首要目标），此处是完整展开。

> 相关：分镜里的声音接点见[镜头语言与分镜](craft-shot-language.md)；动态与口型的配合见[动态化技法](craft-motion-design.md)；声音的权利边界见[权利、安全与平台规则](rights-safety-and-platforms.md)。

## 一、漫剧声音的五条轨

| 轨 | 作用 | 优先级 |
|----|------|--------|
| 旁白 | 交代信息、推进叙事（漫剧的主力） | 最高（可懂度） |
| 对白 | 人物表演与关系 | 最高 |
| 音效 | 落点、空间感、动作重量 | 中 |
| BGM | 情绪底色与节奏 | 中低 |
| 环境 | 场景真实感（风、雨、街声） | 最低 |

**漫剧与真人短剧的关键差异**：漫剧大量依靠**旁白 + 字幕**推进信息，观众对逐帧口型的宽容度高于真人短剧。因此策略应是"**口型提示正确 + 字幕准确 + 音效对点**"，而不是把预算全砸在逐帧精修口型上。

## 二、台词写作

- **字数预算**：中文配音常见语速约 4–5 字/秒。30 秒 ≈ 90–130 字，60 秒 ≈ 180–250 字（含旁白）。
- **一句一个信息**：把"因为三年前那件事，所以我一直不敢回来"拆成两句，中间给一个画面。
- **口语优先**：写出来要能念顺。念不顺就改，不要靠配音演员硬扛。
- **不要解释性台词**：人物不解释自己为什么这么做，让画面与后果说明。
- **信息尽量交给画面**：能用一个动作、一个道具、一个表情说清的，不要写进台词。
- **留呼吸**：每 2–3 句台词之间留半拍到一拍的空隙，配乐和音效才有位置。

## 三、配音

给每一句台词标注：

```
[AUD-ID / CHAR-ID]
台词：……
语言/发音：专名、重音、数字读法
情绪目标：主情绪 + 强度（克制 0.3 / 常规 0.6 / 爆发 1.0）
语速与停顿：按表演需要
声音边界：年龄感、音域、禁止模仿对象
对应镜头/时间码：E01-S003 00:02–00:05
```

- **同一个角色用同一种声音方案**：音色、语速基线、口头禅、发音习惯都要在角色 Bible 里固定，换工具或换配音也要保持一致。
- **多语言**：优先保证目标市场的母语自然度，字幕与配音语言可以不同步（配音用母语、字幕保留原文是常见做法）。
- **克隆边界**：只能克隆本人或有书面授权的声音；不得冒充真实人物、客户或同事。普通合成音同样要核对商用条款与平台披露要求。

## 四、口型的四档方案

| 方案 | 做法 | 适用 | 代价 |
|------|------|------|------|
| 不要求口型 | 侧脸/背身/镜头切走，或台词放旁白 | 大部分叙事镜头 | 最低，且不露破绽 |
| 口型提示 | 生成时打开模型的对话/口型选项，靠模型自洽 | 正脸说话的中近景 | 低；偶有不精确 |
| 局部驱动 | 用音频驱动嘴部或整脸（数字人/口型模型） | 需要看嘴的特写 | 中；需另接工具与硬件 |
| 逐帧精修 | 后期逐镜修口型 | 少数关键镜头 | 最高；不建议全片使用 |

**决策顺序**：先问"这一镜能不能不露嘴"，能就不做；再看模型原生能力；最后才上专门的驱动工具。省下来的预算放到表演、音效与节奏上，观众感受到的差别更大。

## 五、字幕规范

- 每行 **12–18 个汉字**为宜，一行放不下就断行，不要缩小字号。
- 单条字幕停留时间 ≥ 1 秒，且不超过实际语音时长 + 0.5 秒。
- 字幕位置固定，避开平台 UI 覆盖区（竖屏常见做法：下方约 15–20% 区间内）。
- 按实际音频校对，不要照抄剧本（配音时的临场改动要以音频为准）。
- 说话人超过两人时标注说话人；有重要非语言声音时加无障碍提示（如「（门响）」）。
- 专名、数字、外语词统一写法，登记在项目的术语表里。

## 六、混音

- **层级**：人声 > 音效 > BGM > 环境。任何一轨都不允许盖住人声。
- **参考区间**（**以平台文档为准，会变**）：对白 −12 至 −6 dB，BGM −24 至 −18 dB，音效不超过人声；整片响度常取 **−14 LUFS 附近**（不同平台在 −13 至 −16 之间浮动），真实峰值不高于 **−1 dBTP**。
- **不要靠固定音量差**替代试听：耳机、手机外放、笔记本喇叭各听一遍。
- **对白可懂度**是最重要的指标：听不清台词，前面所有工作都白做。
- 音乐与音效必须记录许可与商用范围，见[权利、安全与平台规则](rights-safety-and-platforms.md)。

## 七、音画同步检查

- [ ] 每句台词的起止与画面中说话人的动作对齐？
- [ ] 音效落点落在动作帧上（关门、落物、脚步）？
- [ ] BGM 的进入/退出是否落在镜头接点上？
- [ ] 转场处是否有声音先行或延续，避免"突然安静"？
- [ ] 全片响度是否统一（没有忽大忽小）？
- [ ] 字幕与音频是否逐句对过？
- [ ] 手机外放听一遍，台词是否仍然清楚？

## 八、常见问题

| 症状 | 病因 | 修法 |
|------|------|------|
| 台词塞不下 | 按字数预算超了 | 砍台词，不要加速念 |
| 听着假 | 每句都是完整书面句 | 改口语、加停顿、加语气词 |
| 口型对不上 | 未做口型或时长估错 | 先量音频再定镜头；或改旁白处理 |
| 声音忽大忽小 | 未做响度统一 | 做整片响度标准化 |
| BGM 盖人声 | 层级未定 | 压 BGM，人声优先 |
| 字幕看不清 | 字数太多或位置被 UI 覆盖 | 断行、放大、上移 |
