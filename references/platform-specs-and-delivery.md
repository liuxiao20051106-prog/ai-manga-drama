# 交付规格与多平台分发

在确定交付规格、把一支母版分发到多个平台、或准备发布包时读取。**本页所有数值都是参考区间，不是承诺**；平台文档、编码推荐和内容政策随时变化，发布当日必须重新打开官方页面核对。

> 相关：标识与权利见[权利、安全与平台规则](rights-safety-and-platforms.md)；标题/封面/受众策略见[商业化与分析](commercialization-and-analytics.md)；发布终检见[发布终检](../templates/release-checklist.md)。

## 一、先定母版，再派生

**母版规格**（尽可能高的质量，作为唯一真源）：

- 分辨率按主要投放平台的最高需求定（常见 1080×1920 竖屏，或 1920×1080 横屏）
- 帧率与素材一致（常见 30 fps；有运动内容可用 60 fps）
- 编码：H.264 / MP4 兼容性最好；H.265 体积更小但部分平台兼容性差
- 音频：48 kHz、立体声，导出前做响度统一
- 保留**无字幕、无标识、无水印**的干净母版，便于后续改版与出海

所有派生素材都从母版生成；**不要在每个平台上各剪一遍**——版本一多，改一处就要改十处。

## 二、技术参数参考区间

| 项目 | 竖屏（抖音/快手/视频号/小红书一类） | 横屏（B站/YouTube 一类） |
|------|--------------------------------------|---------------------------|
| 画幅 | 9:16 | 16:9 |
| 分辨率 | 1080×1920（或更高） | 1920×1080（或更高） |
| 帧率 | 30 / 60 fps | 24 / 30 / 60 fps |
| 视频码率 | 约 8–16 Mbps | 约 8–20 Mbps |
| 音频码率 | 128–192 kbps | 192–320 kbps |
| 响度 | 约 −14 LUFS（各平台在 −13 至 −16 之间浮动） | 同左 |
| 真实峰值 | ≤ −1 dBTP | 同左 |
| 编码 | H.264 / MP4 | H.264 / MP4 |
| 安全区 | 上下各留约 15%（字幕与信息放中间列） | 下方约 10% |

**永远以平台发布文档为准**：同一个平台在不同端（App / 网页 / 开放平台）的推荐值也可能不同。

## 三、安全区与字幕占位

- 竖屏的上下边缘会被标题、按钮、评论条、进度条覆盖。把**关键信息（人脸、道具、字卡）放在画面中间列**。
- 字幕固定在一个高度，整片不要跳动。
- 片头的标题卡与片尾的引导卡，也要按安全区排布。
- 做验收时用手机真机看一遍，而不只在电脑上看。

## 四、画幅转换要重构，不要裁切

竖屏转横屏（或反向）时：

1. **重排构图**：可能需要重新生成部分镜头（更宽的景别、更多的环境）。
2. **补环境**：两侧留白要么补画，要么用模糊/纯色处理，不要直接拉伸。
3. **重做字卡**：竖屏的字卡在横屏会显得稀疏，需要重排。
4. **重做安全区检查**。
5. **记录派生关系**：母版 → 派生版本的编号与日期写进[素材台账](../templates/asset-ledger.md)。

同一条内容在不同画幅下"剪切掉了什么"会改变观感，别把画幅转换当成一键操作。

## 五、封面、标题与首帧

- **首帧**：竖屏平台的推荐流默认显示首帧或封面，把最抓人的画面放这里（不要是场景空镜）。
- **封面**：人物占画面比例大、情绪夸张、标题字 3–8 个字、对比度高。
- **标题**：说清"谁 + 遇到什么 + 结果倾向"，不用误导点击。系列作品保持标题结构一致，方便观众追更。
- **简介/标签**：题材、人物关系、更新频率写清楚，便于搜索与推荐。

## 六、平台差异（结构层面，具体规则现场核对）

不同平台在下面这些方面差异最大，**每一项都要单独核对，不能一套规则走天下**：

| 维度 | 需要确认什么 |
|------|--------------|
| 内容定位 | 竖屏快节奏 / 横屏连载 / 女性向 / 悬疑解密 …… 偏好不同 |
| 时长与集数 | 单集时长区间、整季总时长、是否支持连载状态 |
| 入口与资质 | 个人可发 / 需机构 / 需版权证明 / 需分级备案 |
| 版权与 IP | 是否提供开放 IP 库可改编、改编补贴是否要求全版权 |
| AI 标识 | 显式标识位置与形式、是否必须保留元数据隐式标识 |
| 导流限制 | 是否允许站外引导、能否挂载外链 |
| 变现方式 | 分成/保底/付费/商单/订阅，各自的结算与门槛 |
| 数据指标 | 后台可见指标的定义（留存、完播、追集的算法各不相同） |

**注意**：自媒体报道里的保底金额、分成比例、政策名称变动极快，且常有夸大。任何金额、比例、补贴条款都必须以官方发布页或合同原文为准，不要作为规划依据。

## 七、多语言与出海

- **字幕与配音分开决策**：常见做法是配音用目标市场母语、字幕可选保留原文或双语。
- 翻译要重写而不是直译：口语、梗、称谓、度量单位都要本地化。
- 画面中的文字（招牌、手机屏、字卡）**在生成阶段就应尽量留白**，交给后期排版，便于多语言替换。
- 出海平台对 AI 披露的要求可能与国内不同，逐平台核对。
- 文化适配：手势、颜色、节日、宗教与政治敏感元素要按目标市场复核。

## 八、发布包清单

每次交付至少包含：

- [ ] 成片（母版 + 各平台派生版本，命名含集号与版本）
- [ ] 封面图与首帧（含所需尺寸）
- [ ] 标题、简介、标签、话题
- [ ] 字幕文件（含无障碍提示）
- [ ] 素材台账与权利记录（音乐、字体、声音、肖像的许可）
- [ ] AI 标识落实情况说明
- [ ] 质量评分卡与未解决风险列表
- [ ] 发布终检表（含核对日期与链接）

## 九、发布日复核清单

- [ ] 目标平台的当前规格文档（分辨率/码率/时长/响度）重新打开过？
- [ ] AI 标识规则与标识功能在后台确认过？
- [ ] 内容政策与分级要求核对过？
- [ ] 标题、封面、简介没有误导或不实声明？
- [ ] 上传权限与公开发布已获作者单独授权？
- [ ] 上传后真机播放一遍，检查安全区、字幕与音画同步？
