## 示例一：A路线 — 30秒治愈日常漫剧

### 项目信息
- **剧名**：《等一封信》
- **类型**：治愈日常
- **时长**：30秒
- **工具**：DeepSeek + 即梦 + 可灵 + 剪映
- **难度**：⭐ 零基础可完成

### 阶段一：剧本

```
## 第1集：信箱

场景：老旧的公寓楼入口，黄昏

一个20岁的女孩（小满）从公寓出来，习惯性地看了一眼
墙上的旧信箱。空的。她脚步停了半秒，然后继续走。

特写，她手指划过信箱的金属边框，上面贴着一张褪色的
卡通贴纸——一只歪歪扭扭的纸飞机。

画外音（小满的心声）："已经第四十七天了。"

她走出大门，夕阳把她的影子拉得很长很长。

结尾：镜头留在那个空信箱上，信箱的门没关严，微微开
着一条缝——里面好像有什么白色的东西。
```

### 阶段二：角色设计

**主角：小满**
```
一位20岁的女孩，黑色短发齐耳，圆脸，棕色大眼睛温柔
但有淡淡的忧伤，皮肤白皙，身材小巧清瘦。

穿着米白色宽松毛衣，深灰色长裙到脚踝，棕色短靴，斜
挎一个棕色帆布包。左手腕戴一条红色编绳手链（重要道
具）。

常带若有所思的表情，习惯性地抿嘴。

日系治愈动漫风格，新海诚式柔光，暖色调。
```

**人设卡提示词（即梦）**：
```

穿着米白色宽松毛衣，深灰色长裙，棕色短靴，斜挎棕色帆布包，左手腕红色编绳手链。

微微抿嘴，若有所思的表情，正面站立，双手自然下垂。

日系治愈动漫风格，新海诚式柔光，暖色调，纯色背景，角色设定图，三视图，高画质，细节丰富。
```

```

           暖光，电影感，4秒

C03(S03) - 轻微呼吸感，小满的睫毛微微颤动，眼神流转看向信箱，
           光影在脸上缓慢变化，3秒

C04(S04) - 镜头极缓下移，光斑在金属表面微动，贴纸边缘微微翘起，
           4秒

C05(S05) - 手指轻触金属边框，指尖缓慢划过，红色手链随动作微微晃动，
           4秒

           影子随步伐移动拉长，5秒

C07(S07) - 镜头极缓推近信箱门缝，门缝中的白色一点点显露，光影渐暗，
           制造悬念感，5秒
```

### 阶段六：配音与配乐

| 序号 | 内容 | 配置 |
|------|------|------|
| D01 | "已经第四十七天了。" | 年轻女声(小满)、微微叹息、0.9x语速、温柔带淡淡忧伤 |

**BGM**：柔和钢琴独奏，渐入又渐出，不盖过人声
**音效**：开门声(S02)、手指触金属声(S05)、风声(S06)、信箱的轻微金属声(S07)

### 阶段七：合成指引

1. 剪映导入7个视频片段 → 按分镜顺序排列
2. 粗剪 → 每个片段掐头去尾0.5秒
3. 添加配音D01 → 剪映智能口型匹配
4. 添加BGM → 音量设为配音的15-20dB以下
5. 字幕：白色+黑色描边，"已经第四十七天了"出现在S05
6. 导出：1080P竖屏(9:16)，30fps，MP4

## 示例三：C路线 — 本地全自动管线概览

### 管线设计（适合技术用户）

```
Ollama(Qwen2.5-14B)
    ↓ 输出结构化剧本JSON
ComfyUI Workflow（自动化管线）
    ├─ SDXL底模 + 角色LoRA
    ├─ ControlNet(OpenPose + Depth)
    ├─ IP-Adapter（参考加固）
    └─ FaceDetailer（面部精修）
    ↓ 生成全部分镜图
AnimateDiff（ComfyUI节点）
    ├─ 图生视频 Motion Module
    └─ 每镜4-8秒短片
    ↓
GPT-SoVITS
    ├─ 角色A音色 → 台词A
    └─ 角色B音色 → 台词B
    ↓
MoviePy脚本
    ├─ 拼接视频片段
    ├─ 叠加配音音频
    ├─ 添加BGM（MusicGen生成）
    ├─ 渲染字幕
    └─ FFmpeg导出MP4
```

### ComfyUI 工作流核心节点链（概要）

```
Load Checkpoint (SDXL底模)
    ↓
Load LoRA (角色LoRA · 权重0.8)
    ↓
CLIP Text Encode (分镜提示词)
    ↓
Load Image (人设卡参考图) → IP-Adapter Apply
    ↓
Load Image (姿态参考图) → ControlNet (OpenPose)
    ↓
KSampler → VAE Decode → FaceDetailer → Save Image
```

### AnimateDiff 核心参数

```
- motion_module: mm_sd_v15_v2.ckpt
- motion_scale: 根据场景类型调整
  - 对话场景: 0.5-0.8 (轻微动作)
  - 日常场景: 1.0-1.2 (正常幅度)
  - 战斗场景: 1.5-2.0 (大幅运动)
- 帧数: 16帧/片段
- 帧率: 8fps → 后期光流法插值到24fps
- ControlNet: 使用Lineart或Canny保持结构
```

### MoviePy 合成脚本结构（Python）

```python
from moviepy.editor import *
import json

# 1. 加载时间轴数据
with open('timeline.json') as f:
    timeline = json.load(f)

# 2. 拼接视频片段
clips = []
for shot in timeline['shots']:
    clip = VideoFileClip(shot['video_path'])
    if shot.get('speed'):
        clip = clip.fx(vfx.speedx, shot['speed'])
    clips.append(clip.subclip(0, shot['duration']))

final_video = concatenate_videoclips(clips, method="compose")

# 3. 添加配音
voice = AudioFileClip("voice_all.wav")
final_video = final_video.set_audio(voice)

# 4. 添加BGM（背景音轨）
bgm = AudioFileClip("bgm.wav").volumex(0.15)  # 15%音量
final_audio = CompositeAudioClip([voice, bgm])
final_video = final_video.set_audio(final_audio)

# 5. 添加字幕
# （略去字幕生成的详细代码）

# 6. 导出
final_video.write_videofile(
    "output/episode_01.mp4",
    fps=30,
    codec='libx264',
    audio_codec='aac'
)
```

## 示例总结

| 示例 | 工具路线 | 制作时间（单人） | 费用 | 适合人群 |
|------|---------|---------------|------|---------|
| 示例一 | A路线 | 2-3小时/集 | ¥0 | 零基础新手 |
